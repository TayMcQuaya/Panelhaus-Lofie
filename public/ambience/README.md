# Ambience

Every ambience layer is synthesised until a real file is here. Drop in a file with the matching name and it
replaces that layer on the next page load. The browser console says `[ambience] using ...` when it does.

| Layer | File | How it is used |
|---|---|---|
| Rain | `rain.mp3` | Seamless loop |
| Thunder | `thunder.mp3` | A single clap and rumble, played on each lightning strike and now and then in the distance |
| City | `city.mp3` | Seamless loop |
| Clock | `clock.mp3` | Seamless loop (one tick per second) |
| Cat purr | `purr.mp3` | Seamless loop |
